Privacy Policy for Mybrain Drive Sync

Last updated: 2026-11-07

Overview

Mybrain Drive Sync is a personal application developed and operated by its sole user. It synchronizes the user's own Obsidian vault files with the user's own Google Drive account, using the Google Drive API through the Drive Bridge plugin for Obsidian.

Data accessed

The application accesses only the files that the user chooses to synchronize between the user's own devices and the user's own Google Drive. Access is used exclusively to upload, download, and keep those files in sync.

Data storage and sharing

No data is collected for analytics or advertising. No data is sold, shared with, or transferred to any third party. OAuth credentials and tokens are stored locally on the user's own device. The only storage involved is the user's own Google Drive.

Limited Use

The application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
